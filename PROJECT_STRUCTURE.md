# Project structure

- `src/audio/` — browser audio loading and local analysis
- `src/beatmap/` — deterministic music-aware map generation
- `src/gameplay/` — hit windows, scoring and holds
- `src/rendering/` — Canvas renderer and effects
- `src/storage/` — IndexedDB song library
- `src/ui/` — menus and song selection
- `src/workers/` — non-blocking audio feature extraction
- `.github/workflows/` — GitHub Pages deployment
